<h1>GEMU Engine - Hackathon Project</h1>

<p>For this hackathon, our team of designers and developers built the web platform for GEMU Engine, a next-generation voxel game engine.</p>
<h5>UX Design in Collaboration with Designers</h5>
<ul>
  <li>Target-Tailored UI Layout: Analyzed the needs and requirements of key visitor groups—such as game developers, learners, and investors—to structure tailored UI and content.</li>
  <li>User Flow Design: Designed a seamless user journey spanning from engine discovery and early access applications to community FAQ resolution.</li>
  <li>Design System & Visual Concept: Established a modern UI utilizing a dark theme and Glassmorphism effects to convey the technical atmosphere of a next-generation voxel engine.</li>
  <li>Responsive Layout: The responsive layout supports screen resolutions between 1440px and 1920px.</li>
</ul>

<h3>Key Technical Features</h3>
<ul>
  <li>Discord Forum Integration: Dynamically fetches popular FAQ threads and star (⭐) reaction counts in real time using the Discord API.</li>
  <li>Tag-Based Filtering: Allows users to quickly filter and view questions by selecting their category of interest. </li>
  <li>Interactive Access Request & Roadmap: Features an early access application modal that smoothly transitions to an interactive roadmap showing the next steps upon submission.</li>
  <li>Optimized Responsive Layout: Designed with a precise layout tailored to provide an optimal viewing and interactive experience across resolutions ranging from 1440px to 1920px.</li>
</ul>
